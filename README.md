# Portal de Servicios Universitarios — Proyecto Base

Proyecto colaborativo para 24 estudiantes del curso de Aseguramiento de la Calidad de Software.

## Objetivo
Aplicar de forma práctica:
- Git y ramas
- Testing
- Selenium
- Integración Continua (CI)
- Pipelines
- Entrega Continua (CD)
- DevOps
- DevSecOps

## Inicio rápido
1. Abra `index.html` en el navegador.
2. Cada estudiante debe trabajar únicamente en su módulo.
3. Cree una rama individual antes de modificar archivos.
4. No realice cambios directamente en `main`.

## Convención sugerida de ramas
`est01-perfil`, `est02-notas`, ..., `est24-reporte`.

## Requisitos individuales
- 1 funcionalidad implementada.
- Mínimo 3 commits significativos.
- 5 casos de prueba documentados.
- Mínimo 1 prueba automatizada.
- Validaciones de entradas.
- Evidencia del pipeline.
- Revisión por un compañero antes del merge.

## Carpeta tests
La carpeta `tests/` está preparada para agregar las pruebas automatizadas en una fase posterior.

## Importante
Este paquete es intencionalmente un PROYECTO BASE: las 24 funcionalidades no están resueltas.
